# EmberCut releases

Download the latest build from [Releases](https://github.com/embercut-studio/embercut-releases/releases/latest).

| File | For |
| --- | --- |
| `EmberCut-macos-arm64.zip` | EmberCut editor, Apple Silicon Mac |
| `EmberCut-windows-x86_64.zip` | EmberCut editor, Windows |
| `EmberCut-android-arm64.apk` | EmberCut for Android |
| `embercut-server-linux-x86_64-cuda12.8.tar.gz` | Render server, Linux + NVIDIA GPU |
| `embercut-server-windows-x86_64-cuda12.8.zip` | Render server, Windows + NVIDIA GPU |

The render server needs an NVIDIA driver and CUDA 12.8 installed. Check downloads against `SHA256SUMS.txt`.
